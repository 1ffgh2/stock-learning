二、核心：GridSpec 子图布局
--------------------------

Day11 用的 plt.subplots(2,1) 是等分格子。
真实分析图要「主图大、副图小」，用 GridSpec：

  gs = GridSpec(3, 2, height_ratios=[3,1,1.2])  # 行高比例
  ax = fig.add_subplot(gs[0, :])                 # 第0行整行

记住一句话：
  gs[行, 列] 切格子
  gs[0, :] 里的 : = 这一行整行都要
  height_ratios 控制每行高低


三、业余图 → 简历级图 的4个细节
-------------------------------

1. 不等分布局   → 主图占3倍高，信息主次分明
2. 去顶/右边框  → ax.spines['top'].set_visible(False)
3. 网格调淡     → ax.grid(True, alpha=0.25, ls='--')
4. 克制配色     → 定好一套色值，不花花绿绿

一句话：专业感全在留白和克制，不在花哨。


四、中文字体设置（每个notebook开头必跑）
----------------------------------------

matplotlib 默认字体没中文 → 全变方块。
5行解决，全局生效：

  from matplotlib import font_manager
  FONT = '/System/Library/Fonts/Hiragino Sans GB.ttc'
  font_manager.fontManager.addfont(FONT)
  plt.rcParams['font.family'] = 'Hiragino Sans GB'
  plt.rcParams['axes.unicode_minus'] = False   # 负号不变方块

注意：pyenv 3.12 环境和之前的环境字体要各设一遍。
