二、核心工具
-----------

matplotlib — Python画图的老大哥
mplfinance  — matplotlib的金融包装，一行画K线

画图三步骤：
  1. fig, ax = plt.subplots()    → 创建画布
  2. ax.plot/bar/hist(...)       → 在画布上画
  3. ax.set_title/label/grid/... → 装修


三、K线图怎么看
--------------

一根蜡烛 = 一天的四要素：
  最高价 — 上影线顶端
  收盘价 — 实体上沿（阳线）/ 下沿（阴线）
  开盘价 — 实体下沿（阳线）/ 上沿（阴线）
  最低价 — 下影线底端

红柱 = 收盘>开盘 = 涨了
绿柱 = 收盘<开盘 = 跌了

影线长 = 多空打架激烈，价格被拉回


四、量价配合口诀
----------------

价涨量增 → 健康的涨，买盘充足
价涨量缩 → 量跟不上，动能不足
价跌量增 → 恐慌抛售，有人在砸
价跌量缩 → 卖盘衰竭，可能见底


五、均线怎么看
--------------

MA5在上 MA20在下 → 短期强，上涨趋势
MA5跌破 MA20 → 可能转跌（死叉）
MA5上穿 MA20 → 可能转涨（金叉）


六、收益率直方图怎么看
----------------------

最高柱子 = 最常见的日涨跌幅度
均值在0左边 = 整体偏跌（茅台今年就是）
尾巴又长又肥 = 极端涨跌多，风险大
