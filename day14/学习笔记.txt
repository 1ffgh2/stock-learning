三、核心概念：Git 三步走
------------------------

git add .        → 暂存（告诉Git哪些文件要拍照）
git commit -m "" → 存档（拍一张快照，附说明）
git push         → 上传（把本地快照同步到GitHub）

类比：写Word文档
  add    = Ctrl+S（保存草稿）
  commit = 另存为带日期版本号的文件
  push   = 上传到网盘
