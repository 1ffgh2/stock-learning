Day 16 — MACD 指标（⭐重点）
=========================
日期：2026-07-18


一、MACD三要素

DIF（快线）= EMA(12) - EMA(26)
  - DIF > 0 → 短期在长期上方（多头）
  - DIF < 0 → 短期在长期下方（空头）

DEA（慢线/信号线）= DIF 的 9日 EMA
  - DIF 的平滑版，用来和 DIF 对照

MACD柱 = (DIF - DEA) × 2
  - 红柱（正）= DIF 在 DEA 上方 → 动能向上
  - 绿柱（负）= DIF 在 DEA 下方 → 动能向下
  - 柱子变长 = 加速，柱子变短 = 减速


二、手算验证

手写 EMA 递推公式，和 Pandas ewm(span).mean() 结果完全一致。
MACD 没有新东西，就是 EMA 套 EMA。

五、核心认知

□ MACD = EMA思想的迭代应用。EMA(12)和EMA(26)是你会的，DIF是差值，
  DEA是差值的EMA——全是Day15的东西
□ MACD金叉/死叉→落后信号，和MA金叉一样
□ MACD的真正价值不在金叉死叉，在柱状图的动能变化：
  - 柱子变短 = 动能减弱 = 趋势可能反转
  - 顶背离/底背离 → Day 18深入讲
□ 恒瑞医药单次金叉后涨15%不能说明信号有效——看茅台13次的统计才有意义


六、回答 Notebook 三问

❶ MACD的三要素分别是什么？每个是怎么算出来的？

  DIF（快线）= EMA(12) - EMA(26)
    快慢两条EMA的差值。DIF>0=多头，DIF<0=空头。
    数据验证：7月10日茅台 EMA12=1197.88, EMA26=1215.71, DIF=-17.83。

  DEA（慢线/信号线）= DIF 的 9日 EMA
    DIF自己的移动平均，比DIF更平滑。
    数据验证：7月10日 DEA=-22.55。

  MACD柱 = (DIF - DEA) × 2
    DIF和DEA的距离。红柱=DIF在上方，绿柱=DIF在下方。×2只是为了放大看得清楚。
    数据验证：7月10日 MACD柱 = (-17.83-(-22.55))×2 = 9.44（红柱）。

❷ MACD金叉和MA金叉有什么本质区别？哪个信号出现得更早？

  本质区别：
    MA金叉：价格的一阶平滑 → MA(5)和MA(20)比较。
    MACD金叉：价格的二阶平滑+差分 → 先算EMA差(DIF)，再对DIF做EMA(DEA)，比较DIF和DEA。

  MACD信号出现更早。
    证据：茅台近一年MA金叉仅7次，MACD金叉有13次。MACD用了EMA（对最近变化更敏感）
    而且DIF是快慢EMA的差——价格刚转向，差值先变化，DIF就动；MA要等价格实实在在涨
    好几天才拐头。

  但多≠好：MACD金叉胜率46%，MA金叉43%，都不到50%。

❸ 3只股票中，谁的MACD信号最频繁？走势和信号方向一致吗？

  恒瑞医药信号最频繁：13次金叉 + 13次死叉（平均约每14个交易日一次信号）。

  最近一次金叉后走势：
    恒瑞医药 +14.97% → 金叉看涨，确实涨了 ✅
    比亚迪   +1.73%  → 金叉看涨，微涨 ✅
    招商银行 +0.41%  → 金叉看涨，微涨 ✅
    三只都是涨的，这次"方向一致"。

  但别被单次蒙蔽：
    茅台13次金叉回测，胜率46%，平均亏钱。一次准≠信号有效。恒瑞这次赚15%和
    下次亏5%都是同一个信号的随机结果。
